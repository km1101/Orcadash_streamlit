# Orcadash Streamlit

ORCAFLEX post-simulation results console built with Streamlit. Extraction logic lives in `backend/var_and_func` and is shared with the optional Flask API in `backend/`.

## Quick start

```bash
pip install -r streamlit_app/requirements.txt
streamlit run streamlit_app/app.py
```

See [streamlit_app/README.md](streamlit_app/README.md) for the dashboard workflow, architecture, and OrcFxAPI requirements.
